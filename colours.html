Colours

Main recommendation: Dulux Lichen Green 70YY 55/299 with aubergine or brown-aubergine for the music-zone wall.

Recommended Pairing

Main Walls

Lichen Green
Hex: #A8B595
Dulux notation: 70YY 55/299

Use this as the main living-room wall colour. Order as a colour match by brand/name/code where available.

Music Zone

Original Aubergine
Hex: #5C3A58

Use for the back wall/back alcove music-zone feature area, or switch to a warmer brown-aubergine if it works better with the furniture.

Supplier Note

Ordering Colour-Matched Paint

For the main walls, use Dulux Lichen Green 70YY 55/299 as the reference. If using Decorating Centre Online or another paint supplier, enter the brand/name/code where the colour-match product asks for it.

The hex colours are visual references. The paint supplier colour code/name should be used where possible.

Recommended route: Lichen Green main walls with aubergine or brown-aubergine music-zone wall.
