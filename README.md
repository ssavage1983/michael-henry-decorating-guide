# Michael Henry Decorating Guide

A highly customized, responsive, HTML/CSS decorating guide tailored for Michael Henry's Victorian living room. Features accurate 2.81m paint calculations, bespoke wallpaper repair instructions, and a Victorian heritage color palette.

## Local Usage
1. Place your exact image files into the images/ directory:
   - 2d-floorplan.jpg
   - 3d-room-render.jpg
2. Open index.html in any modern web browser to view the guide locally.

## Deployment to Vercel
This project is configured as a standard static site and is ready to deploy directly to Vercel.

If you have the Vercel CLI installed, simply run:
ercel --prod
